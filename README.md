# Business-Webanwendungen: Übungen zu HTML, CSS, JavaScript und JSP

Sammlung der Übungsaufgaben aus der Lehrveranstaltung *Business-Webanwendungen* (Hochschule Ludwigshafen) als Eclipse-Projekt für einen Servlet-Container.

## Inhalt

| Ordner | Inhalt |
|---|---|
| `WebContent/html/` | Formulare (Anmeldeformular, Formularelemente), Rezeptseiten, einfache Seiten mit CSS und JavaScript |
| `WebContent/css/` | zugehörige Stylesheets |
| `WebContent/js/` | kleine JavaScript-Übungen (Formularprüfung) |
| `WebContent/jsp/` | JSP-Beispiele (Hello World, Login-Formular) |

## Hinweise

- Lern- und Übungsmaterial, keine Produktionsanwendung.
- Aus dem Repository entfernt: kompilierte Klassen, Zugangsdaten und urheberrechtlich geschützte Bilder (Comicfiguren). Seiten, die darauf verweisen, zeigen das Bild nicht mehr an.
- Frühere Commits können noch alte Stände enthalten.
